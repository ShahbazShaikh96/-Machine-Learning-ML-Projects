# Website Traffic and Ad Spend Exploratory Analysis

Explores website performance data using R, focusing on page views, ad spend, day-of-week patterns, weekend/holiday indicators, and views per advertising dollar.

## Files

- `Website_Traffic_Ad_Spend_Analysis.Rmd`: source analysis
- `Website_Traffic_Ad_Spend_Analysis.html`: rendered report
- `final_website_stats.csv`: dataset used in the analysis
