# Machine Learning Projects

This repository contains applied machine learning assignments organized by model type and business problem.

| Folder | Project Name | Main Work |
| --- | --- | --- |
| `01_Website_Traffic_Ad_Spend_Analysis` | Website Traffic and Ad Spend Exploratory Analysis | Website metrics, ad spend, page views, weekend/holiday patterns, visual exploration |
| `02_Universal_Bank_KNN_Loan_Classification` | Universal Bank KNN Loan Classification | k-nearest neighbors classification, train/validation/test splits, optimal k selection |
| `03_Universal_Bank_Naive_Bayes_Loan_Prediction` | Universal Bank Naive Bayes Loan Prediction | Naive Bayes classification using online banking and credit-card indicators |
| `04_Pharmaceutical_Firms_KMeans_Clustering` | Pharmaceutical Firms K-Means Clustering | K-means clustering, elbow/silhouette selection, cluster profiling |
| `05_Breakfast_Cereals_Hierarchical_Clustering` | Breakfast Cereals Hierarchical Clustering | Hierarchical clustering, linkage comparison, cereal nutrition cluster profiles |
