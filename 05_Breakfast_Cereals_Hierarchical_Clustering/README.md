# Breakfast Cereals Hierarchical Clustering

Uses hierarchical clustering to identify nutritional profiles among breakfast cereals.

## Main Work

- cleans cereal nutrition data
- normalizes numeric variables
- compares single, complete, average, and Ward linkage methods
- selects cluster count using elbow and silhouette analysis
- profiles cereal groups by calories, sugar, fiber, protein, sodium, fat, and rating

## Files

- `Breakfast_Cereals_Hierarchical_Clustering.Rmd`: source analysis
- `Breakfast_Cereals_Hierarchical_Clustering.html`: rendered report
- `Breakfast_Cereals_Hierarchical_Clustering_Output`: original output artifact
