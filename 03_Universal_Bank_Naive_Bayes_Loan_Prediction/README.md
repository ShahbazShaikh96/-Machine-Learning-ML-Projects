# Universal Bank Naive Bayes Loan Prediction

Uses Naive Bayes classification to estimate personal-loan acceptance based on online banking usage and credit-card ownership.

## Main Work

- builds pivot tables for conditional probability estimation
- computes loan acceptance probabilities manually
- trains a Naive Bayes model
- compares manual probability logic with model output

## Files

- `Universal_Bank_Naive_Bayes_Loan_Prediction.Rmd`: source analysis
- `Universal_Bank_Naive_Bayes_Loan_Prediction.html`: rendered report
- `Universal_Bank_Naive_Bayes_Loan_Prediction_Output`: original output artifact
