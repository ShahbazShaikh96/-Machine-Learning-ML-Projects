# Universal Bank KNN Loan Classification

Applies k-nearest neighbors classification to predict whether a Universal Bank customer accepts a personal loan offer.

## Main Work

- removes ID and ZIP fields
- encodes education categories
- normalizes predictors
- compares k values
- evaluates training, validation, and test confusion matrices

## Files

- `Universal_Bank_KNN_Loan_Classification.Rmd`: source analysis
- `Universal_Bank_KNN_Loan_Classification.html`: rendered report
- `Universal_Bank_KNN_Loan_Classification.pdf`: PDF report
