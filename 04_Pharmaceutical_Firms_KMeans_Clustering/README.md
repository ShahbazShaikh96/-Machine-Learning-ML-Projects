# Pharmaceutical Firms K-Means Clustering

Segments pharmaceutical firms using K-means clustering on selected business and financial variables.

## Main Work

- scales numeric features
- uses elbow and silhouette methods to select cluster count
- builds K-means clusters
- profiles clusters by company characteristics, location, exchange, and recommendation category

## Files

- `Pharmaceutical_Firms_KMeans_Clustering.Rmd`: source analysis
- `Pharmaceutical_Firms_KMeans_Clustering.html`: rendered report
- `Pharmaceutical_Firms_KMeans_Clustering_Output`: original output artifact
